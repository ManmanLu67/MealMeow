# 饱腹条 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 首页用进度条显示从打卡记录重算出的饱腹，口粮加 90，每天前三次零食各加 5，加到 200 时宠物死亡。

**Architecture:** `domain/vitals.ts` 的纯函数按事件重放。`app/satiety.ts` 从近三天的记录收事件。口粮和零食在写入时多算一次「加上这次」，达到 200 就走和漏餐相同的死亡。首页只读结果。

**Tech Stack:** TypeScript，`node --test`，微信小程序。领域代码经 `npm run build:local` 进 `miniprogram/generated/`。

**Spec:** `docs/superpowers/specs/2026-11-26-satiety-notes-design.md`

## Global Constraints

- 一天是逻辑日，04:00 换日。下一顿是事件时刻之后最近的一餐；正好卡在饭点上时，下一顿是再后面的那一餐。
- 每个事件上的饱腹取整数，显示也用整数。还没吃过，或上一顿饭点已过且没有新事件，是 0。
- 正餐把饱腹设为 100，覆盖当前数。口粮加 90，不改食盘。零食在当天有效次数少于 3 时加 5，并改食盘；第四次不加。食盘不超过 100，对应现有那一满盘。
- 重算只用今天、昨天、前天。隐藏或整餐驳回的正餐和口粮不算。零食记录删除则加成消失。零食照片驳回不取消加成。还留着通过照片的正餐仍算。
- 死亡只发生在新按下的口粮或零食把整数加到 200 或以上，且当时宠物活着。先写记录，再死亡。删记录不复活。打开页面不补死亡。没有宠物时可以超过 100，但不会死。
- 已有口粮按加 90 显示。已有零食没有 `boosts` 时不加 5。
- 进度条宽度是 `min(数值, 100)%`，条内文字带百分号，例如 `85%`、`130%`。标签是「饱腹」。
- 健康 0–9、等级、连续天数、漏餐死亡不改。首页不把情绪词贴在宠物上。
- 不上传云函数。不把饱腹另存成一个字段。

## Review Focus

- 事件时刻正好是饭点：新加上的数不能马上变成 0。测试在任务 1。
- 饱腹 190 时正餐打卡回到 100，这次打卡不造成死亡。测试在任务 1 和任务 3。
- 同一逻辑日第四次零食不加、也不能因此死亡。测试在任务 3。
- 删掉造成死亡的口粮或零食，宠物仍是死的。测试在任务 3。
- 只有旧的口粮记录、没有新的按下：打开首页可以显示超过 100，宠物仍活着。测试在任务 2。

**Interfaces:**

- Produces:
  - `SatietyEvent = { kind: 'meal' | 'staple' | 'snack'; at: string; meal?: MealType; date?: string }`
  - `satietyAt(now: Date, events: readonly SatietyEvent[], clocksFor: (date: string) => MealClocks, timeZone: string): number`
  - `bowlSatiety(now: Date, events: readonly SatietyEvent[], clocksFor: (date: string) => MealClocks, timeZone: string): number`
  - `emotionFromHunger(satietyPercent: number): string` 仍叫这个名字。70 及以上「饱足」，40 及以上「满足」，15 及以上「有点饿」，其余「饿扁了」。

- [ ] **Step 1: Write the failing test**

在 `test/vitals.test.ts` 增加 `describe('satiety')`。饭点用 `clocks`，时区 `Asia/Shanghai`。从 `domain/index.ts` 引入 `satietyAt` 和 `bowlSatiety`。

```ts
const clocksFor = () => clocks
const breakfast = { kind: 'meal' as const, at: '2026-11-12T23:30:00.000Z', meal: 'breakfast' as const, date: '2026-11-13' }

it('is 0 with no events and 100 at a meal, then 50 halfway to lunch', () => {
  assert.equal(satietyAt(new Date('2026-11-12T23:30:00.000Z'), [], clocksFor, SH), 0)
  assert.equal(satietyAt(new Date('2026-11-12T23:30:00.000Z'), [breakfast], clocksFor, SH), 100)
  assert.equal(satietyAt(new Date('2026-11-13T01:45:00.000Z'), [breakfast], clocksFor, SH), 50)
  assert.equal(satietyAt(new Date('2026-11-13T04:00:00.000Z'), [breakfast], clocksFor, SH), 0)
})

it('adds at a meal instant against the following meal, not zero', () => {
  const snack = { kind: 'snack' as const, at: '2026-11-13T04:00:00.000Z' }
  assert.equal(satietyAt(new Date('2026-11-13T04:00:00.000Z'), [breakfast, snack], clocksFor, SH), 5)
})

it('adds 90 for a staple and a later meal sets 100', () => {
  const staple = { kind: 'staple' as const, at: '2026-11-13T04:00:00.000Z', meal: 'lunch' as const, date: '2026-11-13' }
  assert.equal(satietyAt(new Date('2026-11-13T04:00:00.000Z'), [staple], clocksFor, SH), 90)
  assert.equal(satietyAt(new Date('2026-11-13T07:00:00.000Z'), [staple], clocksFor, SH), 45)
  assert.equal(satietyAt(new Date('2026-11-13T10:00:00.000Z'), [staple], clocksFor, SH), 0)
  const again = { kind: 'meal' as const, at: '2026-11-13T04:30:00.000Z', meal: 'lunch' as const, date: '2026-11-13' }
  assert.equal(satietyAt(new Date('2026-11-13T04:30:00.000Z'), [staple, again], clocksFor, SH), 100)
})

it('lets three snacks add 15 on top of a full meal and ignores the bowl for staples', () => {
  const at = '2026-11-12T23:30:00.000Z'
  const staple = { kind: 'staple' as const, at, meal: 'breakfast' as const, date: '2026-11-13' }
  const snacks = [1, 2, 3].map((n) => ({ kind: 'snack' as const, at: new Date(Date.parse(at) + n).toISOString() }))
  assert.equal(satietyAt(new Date(Date.parse(at) + 3), [breakfast, staple, ...snacks], clocksFor, SH), 205)
  assert.equal(bowlSatiety(new Date(at), [staple], clocksFor, SH), 0)
  assert.equal(bowlSatiety(new Date(Date.parse(at) + 3), [breakfast, staple, ...snacks], clocksFor, SH), 100)
})
```

把现有 `emotionFromHunger` 断言改成：`100` 和 `70` 是「饱足」，`69` 和 `40` 是「满足」，`39` 和 `15` 是「有点饿」，`14` 是「饿扁了」。
