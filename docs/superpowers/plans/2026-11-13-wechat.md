# 微信接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让小程序页面和两个云函数调用已经测过的命令，不在云函数里再写一套饥饿规则。

**Architecture:** 安装开发依赖 `typescript`，把 `domain/` 和 `app/` 编译到 `cloudfunctions/lib/`。该目录忽略，不入库。`cloudfunctions/api/index.js` 和 `cloudfunctions/settle/index.js` 只做参数校验并调用编译结果。页面把读模型绑到已有的 wxml 上。

**Tech Stack:** 微信云开发，云函数 CommonJS，TypeScript 编译。内容安全这一份只留回调入口，不在测试里请求微信。

**Spec:** `docs/agent/ARCHITECTURE.md` 的组件和边界。页面以 `D:\Project\任务规划\吃饭喵\页面设计.md` 为准。

## Global Constraints

- 云函数不 import TypeScript 源文件。
- `cloudfunctions/lib/` 写入 `.gitignore`。
- 页面动作只有 `home`、`checkin`、`exempt`、`gallery`、`adopt`、`saveMeals`、`deleteCheckin`。调用者 ID 取自云函数登录态，不接受事件体里的 `userId`。
- 定时器保持 `0 * * * * * *`，调用 `runDueJobs`。
- 不新增云函数，不建小组集合，不做抠图。
- 微信开发者工具里的点击本计划写入手工检查，不冒充 `node --test` 已通过。

## Review Focus

- 事件体里带了另一个 `userId` 时，读写的仍是登录用户。测试放在任务 2。
- 页面把 `review: 'passed'` 塞进事件体时不能结算。测试放在任务 2。
- 编译产物被误提交。任务 1 检查 `git status` 不出现 `cloudfunctions/lib/`。

### Task 2: 接上两个云函数

**Files:**
- Modify: `cloudfunctions/api/index.js`
- Modify: `cloudfunctions/settle/index.js`
- Test: `test/api.test.ts`

**Interfaces:**
- Consumes: `saveMeals`、`finishCheckin`、`useStaple`、`removeCheckin`、`homeView`、`galleryView`、`adoptView`、`runDueJobs`、`applyReview`
- Produces: `handleApi(event, deps): Promise<{ ok: boolean, error?: string }>`。`deps.userId` 是登录用户。

- [ ] **Step 1: Write the failing test**

```js
test('the event user id is ignored', async () => {
  let seen = ''
  const result = await handleApi(
    { action: 'home', userId: 'other' },
    { userId: 'self', home: async (caller) => { seen = caller.userId; return { ok: true } } },
  )
  assert.equal(result.ok, true)
  assert.equal(seen, 'self')
})

test('a page event cannot mark a review passed', async () => {
  let reviews = 0
  const result = await handleApi(
    { action: 'review', review: 'passed' },
    { userId: 'self', applyReview: async () => { reviews += 1; return { ok: true } } },
  )
  assert.equal(result.ok, false)
  assert.equal(reviews, 0)
})
```

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test test/api.test.ts`
Expected: FAIL，`handleApi` 不存在。

- [ ] **Step 3: Implement `handleApi` and both entries**

`api/index.js` 从微信上下文取 openId，再调用 `handleApi`。页面动作没有 `review`。`settle/index.js` 调用 `runDueJobs`。另导出 `handleReviewCallback(body, deps)`，只供内容安全回调调用 `applyReview`。未知 `action` 返回 `{ ok: false, error: 'unknown_action' }`。

- [ ] **Step 4: Run test to verify it passes**

Run: `node --test test/api.test.ts`
Expected: PASS
