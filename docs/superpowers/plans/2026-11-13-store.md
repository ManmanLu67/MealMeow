# 存储 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供一份不碰微信的仓库，让打卡和结算用同一套单据读写。

**Architecture:** `app/types.ts` 放下表字段。`app/ports.ts` 只导出 `Store` 接口，命令层只认它。`adapters/memory/memory-store.ts` 导出 `createMemoryStore()`。云数据库适配器和以后的手机本地库适配器都放 `adapters/`，必须实现同一个接口。`test/architecture.test.ts` 检查 `domain/`、`app/` 不依赖平台和具体适配器。

**Tech Stack:** TypeScript，Node 24 的 `node --test`。不新增运行时依赖。

**Spec:** `docs/agent/ARCHITECTURE.md` 的数据流和数据字段。

## Global Constraints

- `subjectType` 只有 `'personal'`。`subjectId` 等于 `userId`。
- `meal_records.status` 只有 `'checked_in' | 'exempt'`。没有 `open`。漏餐不写记录。
- `photos` 是字符串数组，第 0 张是主图。`photoReviews` 与它一一对应，每张照片单独记审核结果。
- `settlement_jobs.status` 是 `'pending' | 'waiting_review' | 'manual_review' | 'settled'`。
- 同一餐的结算结果只有一行。
- 同一用户的写命令必须串行。`Store.runExclusive(subjectId, fn)` 是这个约定的唯一入口，云数据库适配器用事务或锁文档实现，命令内部不能嵌套调用同一个主体。
- `domain/` 不 import `app/`。

## Review Focus

- 定时扫描会不会把已挂起或已结算的任务再捞出来。测试放在任务 2。
- 同一用户、同一天、同一餐写入第二条餐次记录会不会变成两行。测试放在任务 1。
- 同一用户的两个写命令同时到达，会不会交错。测试放在任务 1。

### Task 1: 单据类型和内存仓库

**Files:**
- Create: `app/types.ts`
- Create: `app/ports.ts`
- Test: `test/store.test.ts`

**Interfaces:**
- Consumes: `MealType`、`RecordedStatus`、`MealReview`、`JobStatus`，来自 `domain/index.ts`
- Produces:
  - `MealRecordDoc`: `{ userId, date, meal, status, checkinAt, photos, photoReviews, review, hidden }`
  - `SettlementJobDoc`: `{ subjectType: 'personal', subjectId, date, meal, windowEndAt, status }`
  - `SettlementDoc`: `{ subjectType: 'personal', subjectId, date, meal, outcome: 'fed' | 'starved', hungerBefore, hungerAfter }`
  - `UserDoc`: `{ userId, nickname, timeZone, meals, pendingMeals, stapleLeft, stapleMonth, cooldownUntil, adoptedOn, diedOn, pastPets }`
  - `PetDoc`: `{ userId, hunger, alive, adoptedOn, adoptedAt, endedOn, companyDays, mealsEaten }`
  - `createMemoryStore(): Store`，在 `adapters/memory/memory-store.ts`
  - `Store` 方法：`runExclusive` `getUser` `saveUser` `listUserIds` `getPet` `savePet` `getRecord` `saveRecord` `deleteRecord` `listRecords` `getJob` `saveJob` `listPendingJobs` `listHeldJobs` `listFrozenJobs` `getSettlement` `saveSettlement`
