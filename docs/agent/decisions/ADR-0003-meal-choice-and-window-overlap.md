# ADR-0003: 饭点可选零食，打卡时间不能重合

- Status: accepted
- Date: 2026-11-18

## Context

原来窗口内只能打这一餐，相机在只有一餐待打时直接进入该餐，窗口内记零食会被拒绝。三餐间隔用「至少 2 小时」表述，和窗口本身是否重合是同一件事，但页面和错误文案没有按区间来说。

## Decision

- 有待打的餐时，相机弹出选择：这些餐里的一餐，或另记一份零食。零食不代替该餐，不进结算，不改宠物。
- 没有待打的餐时，相机直接记零食。已打过的餐仍从顶部餐卡进入。
- 三餐打卡时间不能重合。窗口仍是饭点前后 1 小时、左闭右开，所以相邻饭点少于 2 小时拒绝，恰好 2 小时允许。

## Consequences

同一个窗口里可以既有一餐记录，又有一份零食。图鉴会同时看到两者。

## Rejected alternatives

- 窗口内仍禁止零食，只在选择单上显示餐次 — 和「可选某一餐或零食」不符。
- 把恰好 2 小时也算重合 — 左闭右开的端点相接不是区间重合。
