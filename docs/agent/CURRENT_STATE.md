## 5. Decisions

- 宠物增加可选字段 `species`。旧档没有这个字段时按黑猫画。
- 图鉴的星只表示三餐都是打卡。有口粮或只打了一部分会是绿格，没有星。连续天数的算法没改。
- 打卡时段内和未到时段的空盘是同一张描边。白和灰差在格子的底色：白是 `#FFFFFF`，灰是 `#F7F8F9`。
- 三个物种相机沿用「相机/未到饭点」的圆和符号，圆的位置和大小与猫相同。萨摩耶从圆的左侧探出上半个头，嘴咬住圆框，像咬住飞盘；嘴下有两颗顺着下巴方向的白色中空小尖牙。下巴在圆后面，不咬中间的相机符号。圆的位置和大小仍与猫相同。鹦鹉从圆框背后探出头，露在右侧；圆内相机符号的下方和右侧各有一根羽毛，羽尖方向不同。金鱼的水在下半、鱼在水里。金鱼相机的外圆放大到黑猫身体外缘：圆心到身体边缘约 122 像素，原来的圆是 90。耳朵尖更远，没有算进去。鱼、气泡和相机符号没有放大。
- 吃饱和有点饿共用的 `samoyed.png` 嘴和鼻子改成和狗相机同一套：鼻子在上，浅笑在下，没有牙。浅笑下面有一条短的肉粉色舌头，在正中。很饿是平嘴，没有舌头。濒危嘴角下垂，没有舌头。这两张和吃饱一样，鼻子和嘴之间有一条短竖线。眼睛分别仍是睁开、半阖、闭上。
- 2026-11-18：界面锁定。饥饿、健康、等级留在首页左上角。
- 2026-11-18：饭点里点相机，可选还没打的那一餐，也可以另记零食。零食不代替这一餐。没有待打的餐时，相机直接记零食。
- 2026-11-23：饭点内点顶部「待打卡」餐卡，同样先弹出选择：这一餐或零食。已打卡和口粮仍直接进入该餐。没有宠物时，只有「领养」进入领养页；点火柴人只振动，和点动物一样。人和动物同样大。相机在各页位置固定；人的中心和「领养」对齐这条中线，动物不要求对准相机。图鉴没有记录时只显示周历；有打卡、口粮或零食才显示对应格子。
- 2026-11-18：三餐打卡时间不能重合。窗口仍是饭点前后 1 小时、左闭右开，恰好隔 2 小时允许。见 ADR-0003。
